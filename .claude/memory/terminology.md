# Terminology / shorthand decode

- **СС** = **Claude Code** (the CLI tool). NOT the Shell.
  - Note: the Shell project itself is "CcDashboard" / "RTM View Shell"; do not confuse with СС.
- **Shell** = CcDashboard.Web (Blazor Server host).
- **RTM** = RTM Service (Windows Service collecting CC data) + session/chat prefix.

Example: "нужна установка СС в powershell" = install Claude Code via PowerShell.
