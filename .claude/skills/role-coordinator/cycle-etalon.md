## 0. Постоянные правила круга
- Один вопрос оператору за сообщение. Бокс — без вопроса в том же сообщении.
- Ответ оператору: суть по-человечески → таблица поков → «ПОКНУТЬ СЕЙЧАС: …» → (вопрос). Без внутренних номеров вместо смысла.
- Чтение шины: `grep -n '^## <дата>T' coordinator.md devops.md curator.md`, окно — С МОМЕНТА прошлого чтения, не со следующей минуты.
- Через мост из git — только `hash-object --stdin` (из `/`), `rev-parse`, `ls-tree`, `log`, `diff-tree`, `cat-file`. Никогда `status`/`diff`/`add`/`commit`/`reset` — они трогают индекс; `diff HEAD` оставил index.lock (урок 2026-11-07).
- Боксы специалистов не выдаю и не перевыдаю. Свой бокс — только файлом `.ps1` в `.coord/measure/<папка>/` и одной строкой запуска.
- Подписи ассистента в коммитах запрещены; проверка — предикатом нормы 26.09 (`git interpret-trailers --parse`).
- Закрытие в реестре — только словом оператора, отдельным вопросом после живой проверки.

3. Ответ оператору: что поняли, что отдано, таблица, ПОКНУТЬ обе параллельно, ОДИН вопрос — самый важный из открытых.
Пример: слово 21:54 → письмо 19:55:28Z; вопросы о группах ушли по одному, ответы 21:57–21:59 тут же разосланы ролям и записаны.

1. Devops: RUN GREEN, контроли EXACT, TESTED TREE. EXPECTED+EXTRA — разобрать: если лишний красный — тот же общий код (вторая «копия» отсутствует), принять и написать причину в сообщение коммита (пример K19 в 27e4161).
