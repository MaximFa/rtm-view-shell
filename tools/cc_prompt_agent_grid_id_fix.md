## Root Cause

Two unrelated PKs are in play:

| Variable | Source | Example value |
|---|---|---|
| `DashboardWidget.GridId` | Auto-generated by `dashboard_widgets` DB | 7 |
| `RTSUserGrid_Grid.GridId` | Auto-generated by `RTSUserGrid_Grid` DB | 42 |
| `Config.RtsUserGridId` | = `RTSUserGrid_Grid.GridId` stored in ConfigJson | 42 |

`AgentGridWidget` receives `[Parameter] int GridId` = `DashboardWidget.GridId` = **7**.
It calls `init("u7")`.

The simulator parses `7` and queries:
```sql
WHERE g."GridId" = @gridId   -- @gridId = 7
```
But `RTSUserGrid_Grid.GridId` = **42** → **zero rows** → no DB-configured MetricIds
→ new columns never appear.

## Goal — two coordinated fixes

### Fix 1 (ScreenEditorPage.razor)
After `SaveAgentGridRtsCommand` returns, assign `preassignedGridId = rtsUserGridId`.
This makes `SaveDashboardWidgetCommand` set `DashboardWidget.GridId = RTSUserGrid_Grid.GridId`.
From that point both PKs are the same value.

### Fix 2 (AgentGridWidget.razor)
Use `Config?.RtsUserGridId` for the `init()` call (with `GridId` as fallback).
This is the belt-and-suspenders fix: works even for widgets saved before Fix 1 is applied.
