## Форма остановки — прогон не свидетельствует о себе
Завести в скрипте проверку `chk <имя> <ожидание> <измеренное>`: печатает `OK` при совпадении и `STOP` при
расхождении. **Каждый** критерий таблицы предикатов проходит через неё — ни один не подтверждается прозой.
⛔ **Самопроверка прибора обязательна:** один раз вызвать `chk` с заведомо ложным ожиданием (например
`chk sanity 1 2`) и убедиться, что он вернул `STOP`. Вернул `OK` — прибор сломан, работа не засчитывается,
и ни один его `OK` ничего не значит. Вывод самопроверки печатать.
⛔ **Хотя бы одно `STOP` — коммита НЕТ**, обвязка пишется со `status: failed`, в `RESULT` перечисляются
все `STOP`-строки. `status: done` допустим только когда:
- напечатана строка `STOP-предикат: N критериев, STOP=M` с `M = 0`;
- каждая строка `RESULT` проверена греппом по собственному тексту `RESULT` **до** записи в шину
  (то есть отчёт сверен с самим собой, а не пересказан).
