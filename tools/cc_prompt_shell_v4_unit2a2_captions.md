## Форма остановки — прогон не свидетельствует о себе

⛔ Хотя бы одно `STOP` — **коммита нет**, `status: failed`, перечень `STOP`-строк в `RESULT`.
`status: done` — только при `STOP-предикат: N критериев, STOP=0`.
⛔ **`RESULT` обязан содержать строки** `BASE`, `V3`, `STOPS`, `SANITY`, `INDEX`, `SIGN`, `BUS`, `TESTS`,
`BUILD`, `COMMIT`, `RESYNC`. Их наличие **проверяет бокс оператора** после прогона; отсутствующая строка —

### Условие 1 — имя колонки, как его задал пользователь
`_sortColumn` (:259) хранит **`colDef.Id`**, а не имя. Человекочитаемое имя — `colDef.Name` (:82), это то,
что пользователь вписал в настройке колонки. Подпись берёт **`Name`, найденное по `Id`**.
⛔ Печатать `MetricId` или `Id` — запрещено: пользователь увидит внутренний идентификатор вместо своего слова.
⛔ `_sortColumn == null` (сортировки нет) — **подписи нет вовсе**, не «по умолчанию» и не пустая строка.
⛔ Если `Id` не нашёлся среди колонок (колонку убрали из настройки, а сортировка осталась) — подписи нет.
Молча печатать `Id` в этом случае нельзя.

### Условие 2 — одно определение «N из M», с кодом
**N = число строк на текущей странице** — `GetPagedRows(filteredRows).Count` (:65).
**M = число строк после фильтра** — `FilteredRowCount` (:352).
Именно так, и вот почему: подпись описывает **то, что сейчас на экране**, относительно **того, что отобрано**.
⛔ Не брать `_rows.Count` (всего пришло от сервера) как M: при включённом фильтре «из всего» скроет сам факт
фильтрации и подпись начнёт врать. Сколько отфильтровано — отдельный смысл, в эту строку не мешать.
⛔ Если `M == N` (всё отобранное поместилось на странице) — подпись всё равно печатается: «показано 7 из 7»
честно, а исчезающая подпись читается как сбой.
⛔ **Если `M == 0` (фильтр отсёк всё) — подписи «показано N из M» НЕТ.** Причина: в этом случае таблица уже
показывает своё пустое состояние `@L["Widget_NoMatchingAgents"]` (:116), и «показано 0 из 0» рядом с ним
повторяет то же самое числами вместо смысла. Одно сообщение об одном факте.
Подпись сортировки при `M == 0` остаётся: она описывает настройку, а не данные.
В `RESULT` подтвердить обе ветки строкой `COUNT`.

### Условие 3 — тексты в трёх словарях, и RTL
