## ЕДИНИЦА СЧЁТА НАЗВАНА ЯВНО — и она ВХОЖДЕНИЯ, не строки
`grep -c` считает СТРОКИ, `grep -o … | wc -l` считает ВХОЖДЕНИЯ. Две замены на одной строке дают
+2 вхождения и +1 строку. Объём заказан во ВХОЖДЕНИЯХ, поэтому и гейт во вхождениях:
```bash
F=src/CcDashboard.Web/Components/Dashboard/ScreenEditorPage.razor
grep -o 'L\[' "$F" | wc -l      # вхождения обращений к словарю
```

|---|---|---|
| обращения `L[` (вхождения) | 166 | **189** (166 + 23) |
| обращения `L[` (строки, справочно) | 166 | назвать фактическое, гейтом НЕ является |
| 36 литералов по игле ниже | 36 | **0** |

**ТРЕТЬЕ ЧИСЛО — СВЕРКА ПО КАРТЕ, и без неё результат не засчитан.** «Литералов 0» и «`L[` +23»
порознь совместимы с тем, что текст просто ВЫРЕЗАЛИ. Предъявить: каждый из 23 ключей карты
встречается в файле не менее одного раза, и сумма их вхождений = **36**:
```bash

# сумма обязана быть 36; ключ с нулём -> СТОП
```
