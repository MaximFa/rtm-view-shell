## Дефект
Правило оператора «открыл фильтр — клик мимо закрывает» исполняется по КУСКУ РАЗМЕТКИ: обработчик
висит на `<tbody>` своего виджета. Измерено на стенде 20.09: клик по заголовку таблицы, по пагинации,
по пустому месту дашборда и по соседнему виджету попап НЕ закрывают (4 из 4 остаются открытыми);
клик по телу своей таблицы закрывает. Механизм отката черновика ЦЕЛ — лечить надо область слушания.

## Решение (В) — доделать УЖЕ РАБОТАЮЩИЙ механизм, не заводить второй
`IFilterPopupCoordinator` уже существует (`Services/FilterPopupCoordinator.cs`, Scoped,
`Program.cs:130`); оба грида подписаны на `PopupOpened` и закрывают свой попап, когда открывается
чужой (`OnOtherPopupOpened`: `if (ReferenceEquals(owner, this)) return;` -> для `owner = null`
закрываются ВСЕ). Лечение — дать странице-контейнеру способ сказать «закрыть все» и позвать его
по клику на корне страницы.

### 1. `src/CcDashboard.Web/Services/FilterPopupCoordinator.cs`
Добавить в интерфейс и в реализацию:
```csharp

```

примет это за ошибку.
