## E-001 — Оператор: серийная функция + тайм-шеринг через stateful-координаторов (дыра-2) [ЗАРАБОТАНО]

- **Эпизод:** двух-трековый сетап. Оператор хотел продвигаться в обоих через «2 координатора». Сессии **не поллят** — двигаются только по поку; оператор — единственный последовательный планировщик. **Уточнение оператора:** но персистентные координаторы дают продвижение через **тайм-шеринг** (каждый держит состояние → переключение без переплаты за «где остановились»). (Разговор 2026-06-08; `session-coord` §11 + норма `коорд: статус`.)
- **Принцип:** человек-оператор — активная, последовательная функция на критическом пути (истинного параллелизма внимания нет). НО stateful-координаторы превращают это в тайм-шеринг; узкое место сдвигается с пропускной способности на **стоимость переключения контекста**. Рычаг = (а) свёртывание оператор-ходов + (б) дешёвое возобновление.
- **Граница:** универсально для human-in-the-loop мультиагента. Специфично: «no-poll / ход по поку» и `коорд: статус` — детали Cowork.
- **Статус:** ЗАРАБОТАНО.
- **Импликация:** дыра (2). Продукт #1: минимум оператор-гейтнутых ходов + дешёвый context-switch. Метрики: оператор-ходов/прогресс, стоимость переключения.

## E-002 — tool-success ≠ delivery [ЗАРАБОТАНО] *(draft RTM-коорд, ждёт уточнения Lab)*

- **Эпизод:** Edit/Write возвращали «success», но файл молча обрезан на Cowork-mount (PD-005 2026-05-25, PD-006 2026-05-28, PD-007). Поймала верификация (tail/wc/hash vs HEAD), не tool-status.
- **Принцип:** agent-run разработка обязана верифицировать **артефакт** (состояние на диске/HEAD), а не доверять exit-status инструмента как факту доставки. Агент, доверяющий tool-success, отгружает обрезанный код.
- **Граница:** триггер специфичен (partial-write mount); универсально — «инструмент отрапортовал успех ≠ эффект достигнут» в любой агентной системе с побочными эффектами.
- **Статус:** ЗАРАБОТАНО (множ. инциденты).
- **Импликация:** продукт #1, столп «качество верифицируется». Это **разрешающая дисциплина** для «сопровождается агентами».

## E-003 — durable truth живёт ВНЕ рабочей поверхности [ЗАРАБОТАНО] *(draft)*

- **Эпизод:** mount async-дропает записи кросс-view (L-SC-04), фантомные dirents (L-SC-10), обрезал даже `.git/HEAD` (см. E-005); нужен journal↔git reconcile; git (закоммиченный) — единственная надёжная общая истина (L-SC-18).

## E-005 — лоссовый вид → ложный диагноз «повреждение» + опасный «фикс» [ЗАРАБОТАНО] *(draft)*

- **Эпизод:** metrics-2 прочитал `.git/HEAD` через mount (обрезка `v2-backend`→`v2-`), диагностировал повреждение HEAD, предложил `git symbolic-ref HEAD refs/heads/v2` — что увело бы здоровый натив-HEAD с `v2-backend` (8c22a9e), повредив его. Нативная проверка оператора: HEAD здоров = `v2-backend`. 2026-06-08.
- **Принцип:** **никогда не чини каноническое общее состояние по одному (возможно лоссовому) виду** — сверься с авторитетным хранилищем (native/origin) до любой починки. Уверенный мисрид + правдоподобный «фикс» опаснее самой фантомной «проблемы».
- **Граница:** триггер специфичен (обрезка чтения mount); универсально — «диагноз из деградировавшего вида + лечение» = класс отказа везде, где агенты наблюдают общее состояние через несовершенный канал.
- **Статус:** ЗАРАБОТАНО (живьём 2026-06-08).
- **Импликация:** продукт #1 — apparatus обязан гейтить «починки канонического состояния» за верификацией по авторитетному хранилищу; сессия не действует по собственному деградировавшему чтению.

## E-006 — harvest сам требует no-loss поверхности захвата (мета) [ЗАРАБОТАНО] *(draft)*

- **Эпизод:** E-002..005 несколько ходов жили **только в чате**; оператор спросил «всё фиксируешь? ничего не потеряется?» — обнажив, что эфемерный чат ≠ фиксация. RTM-координатор не может писать дом Lab (mount-ограничение) → захват пришлось маршрутизировать на поверхность, которую он РЕАЛЬНО пишет (`Evidence-Log.md` в RTM-mount), и потом синкать.
- **Принцип:** петля обучения не лучше своей поверхности захвата; маршрутизируй каждый эпизод **немедленно** в долговечное хранилище, которое захватчик действительно может писать — никогда не полагайся на эфемерный канал (чат/память разговора) или на поверхность, недостижимую захватчику.
- **Граница:** универсально для любого «lessons learned»; специфично — асимметрия кросс-mount записи.
- **Статус:** ЗАРАБОТАНО (этот самый обмен).
- **Импликация:** продукт #1, столп-5 (самообучение) — harvest-конвейер обязан явно определить поверхность захвата + шаг синка, иначе «процесс учится из аварий» проваливается на шаге захвата.

## E-010 — deploy-состояние должно быть самоописываемым (registry/ledger), иначе апгрейд = археология [ЗАРАБОТАНО] *(draft)*

## E-015 — psql NOTICE→stderr→PowerShell terminating-error прервал деплой на полпути БЕЗ отката [ЗАРАБОТАНО] *(draft)*
- **Эпизод:** Phase 5 (re-apply functions) оркестратора 5a16226 на 234 упал на ПЕРВОМ файле 01_ngc_functions.sql из-за БЕЗВРЕДНОГО NOTICE «function ... does not exist, skipping» (DROP IF EXISTS). psql пишет NOTICE в stderr; PowerShell (нет $ErrorActionPreference=Continue вокруг psql) сделал из stderr terminating NativeCommandError -> скрипт АБОРТИРОВАЛ. -AutoRollback НЕ сработал (нет rollback в логе; ловит только ненулевой exit фазы, не abort скрипта). Итог: migrations 5/5 ✅, binaries new ✅, functions 02/03/04 НЕ применены, RTMService+RTMViewShell ОСТАНОВЛЕНЫ -> 234 down. Тест-сервер. 2026-06-08.
- **Принцип:** деплой-оркестратор обязан отличать диагностический stderr-шум (NOTICE/progress) от реальной ошибки; на платформах, где stderr=ошибка (PowerShell native), оборачивать внешний CLI ($ErrorActionPreference=Continue + ON_ERROR_STOP внутри psql). Иначе безвредный NOTICE рвёт прогон на полпути, оставляя систему полу-применённой БЕЗ отката — двойная беда: не довёл И не откатил. Auto-rollback должен срабатывать на ABORT скрипта, не только на ненулевой exit фазы.
- **Граница:** универсально для оркестрации внешних CLI с stderr-диагностикой; специфично — psql NOTICE + PowerShell NativeCommandError (§29.8/§35 знали проблему, hardening не покрыл Phase 5).

## E-019 — физически разнесённые координаторы: git-канал декаплит контент от курьера, но не триггер [ЗАРАБОТАНО] *(draft)*
