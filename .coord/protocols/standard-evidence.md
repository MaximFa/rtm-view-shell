## 2026-09-17 · GIT ЧЕРЕЗ МАУНТ

**Повод.** `shell-0912` запустил `git status --porcelain` через маунт и спросил, где граница.
Предмет поднял `coordinator-0912`; формулировка куратора, аккаунт `gmail`.
**`GIT_OPTIONAL_LOCKS=0`** [измерено 2026-09-17 куратором, этот репозиторий, git 2.34.1]:
`GIT_OPTIONAL_LOCKS=0 git status --porcelain` через маунт **завис и был убит по таймауту 120 с**.
`index.lock` после не остался, но команда не вернулась. Переменная снимает необязательную блокировку,
а не стоимость обхода дерева по мосту.
**Проверка догадки о носителе** [измерено 2026-09-17]: `index.lock` в роль-скиллах — `role-devops` 2,
`role-coordinator` 1, у остальных **десяти ролей 0**. Знает тот, у кого правило в постоянном слое;
не знает тот, у кого оно только в загрузочном. Это не забывчивость ролей, а свойство носителя.
