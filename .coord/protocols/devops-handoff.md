## §5 УРОКИ, КУПЛЕННЫЕ ДОРОГО

1. **«В продукте нет X» требует поиска по ВСЕМ рефам** (`git log --all --grep`, `git rev-list --all` +
   `git grep`), а не проверки одной ревизии; ответ, привязанный к ревизии, обязан её называть.
   Я на этом соврал оператору («мульти-таргета нет» — смотрел только `v3`).
2. **Сообщение коммита — не предикат.** И `git show --stat` врёт при смене EOL: сырые 1084/596 строк
   оказались реальными 37 и 13 при `-w --ignore-cr-at-eol`.
3. **Правка конфига строковой заменой обязана нести guard** `$new -eq $old` → СТОП, а перезапуск службы —
   только после чтения значения С ДИСКА. Боевые JSON прогонялись через `ConvertTo-Json` и имеют **два**
   пробела после двоеточия — литералы из репозитория по ним не матчатся, нужна регулярка со `\s*`.
   Моя правка без guard'а молча стала no-op, и сервис поднял боевой адаптер.
4. **Свойство одной машины нельзя переносить на другую без замера.** «Боевой адаптер Disabled и не
   стартует» — Disabled он на 140, а на 234 Manual. Запустился.
5. **Имена named pipe нельзя мерить путевыми командлетами** (`Split-Path`, `Test-Path`,
   `Get-ChildItem`) — молча врут. Только `[IO.Directory]::GetFiles("\\.\pipe\") | %{ $_.Substring(9) }`,
   контроль — напечатать первые N имён; пустой вывод при ненулевом `.Count` = замер сломан.
6. **Имена таблиц и колонок — из `information_schema`, не из головы.**
7. **`/health` 200 — ложноположительный критерий живости.** HTTP-хост поднимается независимо от движка.
8. **`Set-Content -Encoding UTF8` пишет BOM** → `psql -f` падает. Только
   `[IO.File]::WriteAllText(..., New-Object Text.UTF8Encoding($false))` + проверка первых байт (`7B`).
9. **`$ErrorActionPreference = "Stop"` + NOTICE от psql в stderr** рвёт прогон. Судить по `$LASTEXITCODE`.
10. **Кавычки `\"` в аргументах нативного exe PowerShell съедает.** SQL — только файлом и `-f`.
11. **`Format-Hex -Count` и `Invoke-WebRequest -SkipCertificateCheck` — PS7-only**; на 234 PowerShell 5.1.
12. **Экран логина причину не различает:** `LoginCommand.cs:24-37` отдаёт «Invalid username or password»
    для `UserNotFound`, `AccountDeactivated` и `AccountLocked`, и то же видно при неразрешённом тенанте.
13. **`return` как «стоп» в ран-боксе не работает** — консоль исполняет строки по отдельности.
    Guard — блок или настоящий файл-скрипт.
14. Нормы оператора: **одна задача — один ответ**; **«ГДЕ БЕЖИМ»** с явным указанием машины перед каждым
    ран-боксом; пароли — только маскированным вводом.
