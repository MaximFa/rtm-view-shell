## ШАГ 7 — ФОРМА
Заголовок письма: `## <полная метка из date -u> <автор> -> <адресат>: <суть>`. Маска вместо цифр
запрещена. Число входит в письмо только из вывода УЖЕ выполненной команды. Ноль предъявляется
с положительным контролем ИЗ ТОЙ ЖЕ команды и с названной областью. Ход заканчивается следом
либо названным ожиданием чужого слова с указанием, ЧЬЕГО. Оператору — суть по-человечески,
без таблиц и номеров пунктов, один вопрос за сообщение, ран-бокс отдельно.
