# Script Structures, Short-Version Recipe & Storyboard

Read this when writing a full video ad script or turning a script into a
shootable/editable plan.

## The full converting skeleton (UGC video ad)

| Beat | Purpose | Seconds (long) |
|---|---|---|
| 1. Hook | Stop scroll + open loop | 0–3 |
| 2. Problem + agitation | Name pain in their words; it worsens if ignored | 3–15 |
| 3. Failed attempt | "Tried the obvious fix, it made it worse" | 15–25 |
| 4. Discovery + mechanism | Product as turning point + *why it works* | 25–40 |
| 5. Result / transformation | Concrete before→after, the dream result | 40–55 |
| 6. Offer | Discount/bundle + reason + scarcity/urgency | 55–62 |
| 7. CTA | One clear action | 62–68 |

Principles mapped: beat 3 pre-handles objections (relatability); beat 4 builds
"belief in success" (Value Equation) via the unique mechanism; beat 5 sells the
result (LF8); beat 6 uses scarcity + urgency; the whole thing is WIFM-driven.

## Worked example — travel pillow, transport / neck-pain (Hebrew)

> נרדמתם באוטובוס וקמתם עם צוואר תפוס? זו הסיבה. *(הוק)*
> בתור מישהו שנוסע כל יום בתחבורה ציבורית, כל תנומה קצרה בדרך נגמרה בצוואר תפוס וכאב כל היום. הראש נופל הצידה והצוואר במצב לא טבעי. *(בעיה + הסלמה)*
> ניסיתי הכל — לגלגל סווטשירט, להישען על החלון, אפילו כרית פרסה רגילה. שום דבר לא באמת תמך. *(ניסיון שנכשל)*
> ואז חבר המליץ לי על כרית הנסיעות של מורלן — כרית ארגונומית שתומכת בראש מכל הכיוונים ב־360 מעלות ומורידה את העומס מהצוואר. *(גילוי + מנגנון)*
> כבר מהנסיעה הראשונה ירדתי מהאוטובוס בלי כאב — רגוע ורענן. *(תוצאה)*
> תלחצו על הלינק למטה והספיקו לנצל 50% הנחה לזמן מוגבל. *(הצעה + CTA)*

## Short-version recipe (~45s)

Keep: hook (2–3s) → one-line problem → mechanism (the 360° "why") → one result
line → offer + CTA. Cut: extended agitation, the failed-attempt story (or
compress to half a sentence), secondary benefits. Test short vs long — cold
traffic often prefers short.

## Storyboard format (script → editable plan)

For each beat give four columns so the editor can assemble it directly:

**Seconds · Spoken line (VO) · On-screen caption · B-roll + search terms**

Example row:
`25–40s · "ואז גיליתי את כרית הנסיעות של מורלן..." · "תמיכה מלאה בצוואר 360°" · product demo clip showing 360° support (use own/supplier footage — this builds belief)`

Editing notes to include every time:
- Captions always on (most watch muted); large, high-contrast, RTL for Hebrew.
- Fast cut in the first second (contrast grabs the eye).
- The product-demo / mechanism shot is non-negotiable — it creates belief.
- B-roll only from license-safe sources (Pexels, Pixabay, Mixkit, Coverr). Never
  rip copyrighted ads/films — platforms issue strikes.
- Export 9:16 (Reels/Stories) and 4:5 (feed).
- Name files `avatar_angle_hookN` so winners are identifiable.

## Other formats

**Product page:** hero headline (result + mechanism) → subhead → 3–5 benefit
bullets (each a benefit, not a feature) → social proof block → FAQ that handles
objections (shipping time, sizing/fit, guarantee) → offer with anchored price.

**Ad primary text (Meta):** hook line → 2–3 lines problem→mechanism→result →
CTA + link. Keep first line punchy (it's what shows before "see more").

**Email/SMS:** subject = curiosity or benefit; body short, one idea, one CTA.
