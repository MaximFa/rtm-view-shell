The vendor brand for the RTM View Shell Data Connector documents is **INSIGHTENSE**
(tagline: "AI insights with a sense for excellence"). Product = RTM View Shell Data Connector;
company/brand on covers & headers = INSIGHTENSE.

**Logo files:** `docs/assets/brand/Logo Files/` — variants Black / Color / White (no background) +
Color-with-background, each as PNG (3163×746, ~4.24:1 lockup), SVG, PDF; plus Favicons/.
Use **White logo** on dark backgrounds (cover), **Color logo** on light (headers/footers).

**Palette (sampled from the logo):** primary `#0F3D3B` (deep teal-green), accent `#2ECC71`
(vivid green), background cream `#F5F2F2`. Derived dark `#0A2B29` for gradients.

**Fonts used in the design-skill HTML/PDF version:** Poppins (headings, fits the modern tech brand),
Source Sans 3 (body), JetBrains Mono (code).

Applied so far to the document-design HTML/PDF edition
(`docs/bi/RTM_View_Shell_Data_Connector_EN.{html,pdf}` — cover white logo on teal gradient,
color logo in footers). NOT yet applied to the three `.docx` editions (pending operator go-ahead).
