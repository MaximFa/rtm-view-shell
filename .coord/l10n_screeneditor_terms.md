## 3. ⛔ Две пары, где текст УЖЕ разъехался — находка, а не оформление
```
строка  167 : Delete template      строка 2212 : Delete Template
строка  202 : Save as template     строка 2176 : Save as Template
```
Один и тот же смысл набран в двух регистрах: кнопка в панели и заголовок модального окна.
Сводя их к одному ключу, мы не только локализуем, но и чиним расхождение, которого сегодня
никто не видит, потому что обе надписи английские. **Канонический вариант беру заглавный**
(`Save as Template`, `Delete Template`) — он стоит в модальных окнах, то есть в более заметном месте.
Если координатор решит иначе — меняется одно значение в словаре, разметки это не касается.
