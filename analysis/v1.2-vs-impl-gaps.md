**Purpose:** Identify every divergence to feed into TZ v1.3 update and supporting ADRs.

---

## Marker legend

| Marker | Meaning |
|---|---|
| **NEW-NN** | Requirement / feature present in implementation but absent from v1.2 TZ |
| **CHG-NN** | Requirement exists in v1.2 but has been changed in implementation |
| **TGT-NN** | Existing requirement has been **tightened** (stricter than v1.2 wording) |
| **CLR-NN** | Existing requirement has been **clarified** (wording made unambiguous) |

For each gap also identify:
- **Source of truth:** where the current state is documented (CLAUDE.md section, code file, wireframe, commit)
- **ADR candidate:** Yes / No / Already in ADR-NNN — is this a decision worth an ADR?
- **Target v1.3 section:** which TZ section should incorporate this
